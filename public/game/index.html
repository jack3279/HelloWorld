Overworld Demo

用现有方块、生物、物品和 HUD 素材做的横版试玩。

  • AD 或方向键移动
  • 空格 / W 跳跃
  • J / 鼠标左键 挥剑、拉弓/弩、掷三叉戟、举盾、开关木门、触发观察者/活塞/发射器、剪羊毛、点火、锄地、挖矿、扔珍珠/雪球、套鞍骑马、坐船/矿车、拴绳、打开工作台/箱子/熔炉/酿造台、附魔、吃蛋糕、放唱片
  • Shift 潜行 / 下马 · Ctrl 冲刺
  • F 把选中格和副手对调 · 0 选中副手
  • Q 扔掉快捷栏里选中的物品
  • 1–9 切换快捷栏 · 工作台里点配方或按 1–6 合成

房子里有工作台、熔炉、酿造台、附魔台、唱片机、箱子和漏斗。东墙是铁门，门外有观察者、活塞、发射器和金/钻石/绿宝石块。池塘边有海绵和蓝冰，天上有云可以站。岩浆湖旁有下界传送门，木台下有末地传送门。木板上有铁轨矿车。把 5 颗钻石 放进箱子通关。
