Overworld Demo

九个关卡，各有任务：种田（骨粉催熟）、打猎、钓鱼、采石挖掘、搭桥放置、挖矿炼铁、守夜、探索主世界、下界。素材都来自现有方块、生物和 HUD。

  • AD 或方向键移动 · Shift 冲刺 · C / Ctrl 潜行
  • 空格 / W 跳跃
  • J / 鼠标左键 按住挖掘、拉弓、使用、睡觉、种植、打开工作台或箱子、熔炉烧矿；手上拿着泥土、圆石或木板时对着空位放置
  • Q 扔掉快捷栏里选中的物品 · I 打开 27 格背包
  • 1–9 或点击下方快捷栏、滚轮切换手持物品；手里会显示对应工具或武器 · 工作台里点配方或按 1–6 合成 · 死了按 R 在床边重生（世界不重置）
  • 第一关做面包：锄地 → 种小麦种子 → 收割金麦 → 工作台用 3 个小麦合成面包 → 放进箱子
  • 采石关按住镐挖石头捡圆石；搭桥关选中圆石站在悬崖边一块块放置，按 C 潜行不容易掉进岩浆
  • 通关后按 N 下一关，按 R 重玩本关；九关都完成后按 R 回选关

点下面一关开始，或从第一关按顺序玩。把任务物品放进箱子、挖掘、放置方块、钓鱼、击杀怪物或走进传送门即可过关。死了按 R 重生，世界不重置。
