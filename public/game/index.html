Overworld Demo

用现有方块、生物、物品和 HUD 素材做的横版试玩。地图里有农场、矿洞、沙漠、雪原、遗迹和下界。

  • AD 或方向键移动 · Shift 冲刺 · C / Ctrl 潜行
  • 空格 / W 跳跃
  • J / 鼠标左键 按住挖掘、拉弓、使用、睡觉、种植、打开工作台或箱子、熔炉烧矿
  • Q 扔掉快捷栏里选中的物品
  • 1–9 切换快捷栏 · 工作台里点配方或按 1–6 合成

房子里有工作台、熔炉和箱子。用锄耕地、铲出草径，骨粉催熟作物。动物掉生肉，熔炉或营火能烤熟；木炭能当燃料。钓鱼、挤奶、堆肥、附魔都要经验。把 5 颗钻石 放进箱子通关。
