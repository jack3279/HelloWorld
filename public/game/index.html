Overworld Demo

七个关卡，各有任务：种田（骨粉催熟）、打猎、钓鱼、挖矿、守夜、探索主世界、下界。素材都来自现有方块、生物和 HUD。

  • AD 或方向键移动 · Shift 冲刺 · C / Ctrl 潜行
  • 空格 / W 跳跃
  • J / 鼠标左键 按住挖掘、拉弓、使用、睡觉、种植、打开工作台或箱子、熔炉烧矿
  • Q 扔掉快捷栏里选中的物品 · I 打开 27 格背包
  • 1–9 切换快捷栏 · 工作台里点配方或按 1–6 合成 · 死了按 R 在床边重生（世界不重置）
  • 通关后按 N 下一关，按 R 重玩本关；七关都完成后按 R 回选关

点下面一关开始，或从第一关按顺序玩。把任务物品放进箱子、钓鱼、击杀怪物或走进传送门即可过关。死了按 R 重生，世界不重置。
